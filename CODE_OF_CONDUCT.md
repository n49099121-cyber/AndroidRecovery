# Code of Conduct

## Our Commitment

The AndroidRecovery project is committed to providing a welcoming, respectful, and professional environment for everyone who contributes to or participates in the project.

We welcome contributions from people with different backgrounds, experiences, skills, and perspectives.

## Expected Behavior

Participants are expected to:

* Be respectful and professional.
* Communicate constructively.
* Focus on technical issues and project goals.
* Give and receive constructive feedback.
* Respect different viewpoints and approaches.
* Credit other contributors appropriately.
* Protect private and sensitive information.
* Follow the project's security and responsible-disclosure practices.
* Act in the best interests of the open-source community.

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment, discrimination, threats, or intimidation.
* Personal attacks or deliberately hostile behavior.
* Trolling or persistent disruptive behavior.
* Publishing private or sensitive information without permission.
* Misrepresenting another person's work or contributions.
* Maliciously submitting code intended to compromise users, devices, or project infrastructure.
* Attempting to bypass the project's security boundaries without an authorized security-testing purpose.
* Deliberately introducing malware, credential theft, or unauthorized data collection.
* Any other behavior that would reasonably make the project unsafe or unwelcoming for contributors.

## Security and Responsible Research

AndroidRecovery is a security-sensitive project.

Security research and testing should be performed only on devices, accounts, systems, and data for which the researcher has appropriate authorization.

Security vulnerabilities should be reported according to `SECURITY.md` rather than being publicly disclosed through project discussions or issues.

## Enforcement

Project maintainers may take appropriate action when this Code of Conduct is violated.

Possible actions may include:

* Requesting that inappropriate behavior stop.
* Removing inappropriate content.
* Closing or moderating discussions.
* Temporarily restricting participation.
* Removing participation privileges.
* Other reasonable actions necessary to maintain a safe and productive project environment.

Actions will be considered based on the circumstances and severity of the behavior.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the project maintainers.

For security vulnerabilities, follow the process described in `SECURITY.md`.

When making a report, provide relevant information while avoiding unnecessary disclosure of private or sensitive data.

## Scope

This Code of Conduct applies to project spaces and activities, including:

* GitHub issues.
* Pull requests.
* Discussions.
* Code reviews.
* Project documentation.
* Community communication related to AndroidRecovery.
* Other project-maintained communication channels.
